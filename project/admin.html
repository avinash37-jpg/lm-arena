Quick Actions

How it works

  1. Edit any section from the sidebar (menu, gallery, events, etc.).
  2. Changes are auto-saved to your browser (local draft).
  3. Click 👁️ Preview Changes to see them on the website.
  4. When ready, go to 🚀 Publish / Export to download the new data file.
  5. Upload that file to Hostinger File Manager, replacing js/data.js.
🔒 Security: Rename this admin file to a secret URL (e.g. manage-lv7428.html) and update links.

🔑 Change Admin Password

Password is stored as a SHA-256 hash in js/data.js. After changing, publish to make it permanent.

🚀 Publish Your Website

Step 1 — Download data file

Click below to download a new data.js containing all your edits.

Step 2 — Upload to Hostinger/Vercel

  1. Log in to Hostinger hPanel (or Vercel/Netlify).
  2. Open Files → File Manager → public_html/js/.
  3. Upload the downloaded data.js — overwrite the old one.
  4. Hard-refresh your website (Ctrl+Shift+R) in an incognito tab.

Step 3 — Clear local draft

After publishing, clear the browser draft so future edits start from live.

⚠️ Backup tip: Before overwriting, download the existing data.js from Hostinger as a backup.
